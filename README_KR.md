# 「퇴근하겠습니다!」 수업실 배포 안내

이 버전은 서버나 API 키 없이 돌아가는 정적 웹게임입니다. 따라서 각 교수가 자신의 GitHub Pages에 올려도 같은 방식으로 실행됩니다.

## 학생용 링크

- **강의실 대형 화면 게임:** 사이트 기본 주소
- **개인 듣기·쓰기 훈련:** 사이트 주소 끝에 `?mode=solo`

개별 훈련에서는 브라우저의 영어 읽어주기 기능을 사용합니다. 생도는 문장을 원하는 만큼 반복해서 듣고 받아쓴 뒤, 주어진 상황에 맞춰 한 문장으로 보고합니다. 음성은 Chrome 또는 Edge에서 실행하는 편이 가장 안정적입니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 모든 파일과 폴더를 저장소에 올립니다. `.github` 폴더도 포함해야 합니다.
3. 저장소의 **Settings → Pages**로 들어갑니다.
4. **Build and deployment**의 Source에서 **GitHub Actions**를 선택합니다.
5. `main` 브랜치에 올리면 자동으로 배포됩니다. **Actions** 탭의 작업이 끝난 뒤 Pages 주소를 수업 링크로 쓰면 됩니다.

이미 제공된 `.github/workflows/deploy-pages.yml` 파일이 `dist` 폴더만 GitHub Pages에 올립니다. 별도 서버 설정은 필요 없습니다.

## 수업 내용 바꾸는 곳

- 강의실 게임 문항·선택지·대사: `dist/game.mjs`
- 개별 듣기·쓰기 훈련 문항: `dist/app.js` 상단의 `drills`
- 화면 디자인과 움직임: `dist/style.css`, `dist/motion.mjs`

## 수업에서 쓰는 방식

교수자는 기본 주소를 전면 화면에 띄워 “강의실 게임 시작”으로 함께 진행합니다. 이후 생도는 각자 컴퓨터에서 같은 주소 뒤에 `?mode=solo`를 붙여 개인 훈련을 합니다. 개인 입력 내용은 기기 안에서만 처리되고 저장·전송되지 않습니다.
