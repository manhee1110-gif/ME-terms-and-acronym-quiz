# 「임무 수행하겠습니다!」 수업실 배포 안내

이 버전은 서버나 API 키 없이 돌아가는 차시 선택형 정적 웹게임입니다. 각 교수가 자신의 GitHub Pages에 올려도 같은 방식으로 실행되며, 여러 생도가 동시에 접속해도 각자의 브라우저에서 독립적으로 작동합니다.

## 현재 구성

- **1차시:** 최종 교안의 군사용어·약어, NATO 음성기호, 군 통신 숫자발음·시간·DTG
- **2–4차시:** 첫 화면에 준비 중으로 표시
- **강의실 게임:** 3명의 가상 인물과 이어지는 3개 단계, 상황형 객관식 24문항
- **개별 훈련:** 핵심 16개 활동의 듣기·받아쓰기, 문자·숫자 해독, 한 문장 보고

개별 훈련은 브라우저의 영어 읽어주기 기능을 사용합니다. 음성은 Chrome 또는 Edge에서 실행하는 편이 가장 안정적이며, 학생의 입력은 기기 안에서만 처리되고 저장·전송되지 않습니다.

## GitHub Pages에 올리는 방법

1. 이 폴더의 모든 파일과 폴더를 저장소에 올립니다. `.github` 폴더도 포함해야 합니다.
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Build and deployment**의 Source에서 **GitHub Actions**를 선택합니다.
4. `main` 브랜치에 올리면 자동으로 배포됩니다. **Actions** 작업이 끝난 뒤 Pages 주소를 수업 링크로 사용합니다.

이미 포함된 `.github/workflows/deploy-pages.yml`이 `dist` 폴더만 GitHub Pages에 배포합니다. 별도 서버 설정은 필요 없습니다.

## 다음 차시를 추가하는 곳

차시별 데이터는 `dist/lessons.mjs` 한 파일에 모여 있습니다. 새 차시 객체에 다음 내용을 넣고 `available: true`로 바꾸면 첫 화면에서 해당 차시가 열립니다.

- 차시 제목과 설명
- 게임 내 단계별 상황
- 객관식 문항·힌트·피드백
- 개별 듣기·쓰기 훈련

화면 구조를 새로 만들 필요는 없지만, GitHub Pages는 실제 DB 서버가 없는 정적 사이트이므로 데이터 파일을 수정한 뒤 저장소에 한 번 올려야 합니다. 업로드 후 배포는 GitHub Actions가 자동으로 처리합니다.

## 수업에서 쓰는 방식

교수자는 사이트 기본 주소에서 차시의 **강의실 게임**을 선택해 전면 화면으로 진행합니다. 생도는 같은 첫 화면에서 해당 차시의 **개별 훈련**을 선택하면 됩니다. 1차시 개별훈련 직접 링크는 `?mode=solo&lesson=lesson-1`을 주소 뒤에 붙여 사용할 수 있습니다.
